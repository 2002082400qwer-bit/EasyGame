# 横版动作原型实现计划

**Goal:** 在 MX002 实现可运行的 C + raylib 左右走、跳、蹲、冲刺原型。

**Architecture:** 将纯 C 控制器与 raylib 渲染分开。使用固定时间步与现有侧面图集；中文路径从 Windows 宽字符 API 读取。

**Tech Stack:** C99、raylib 6.0、便携 GCC、PowerShell。

**Spec:** `docs/superpowers/specs/2026-10-13-movement-design.md`。

## 全局约束

- 所有新函数、参数、变量、宏写中文注释；第三方原文件保留。
- 原始图片不修改；本地 Git 记录工程代码、需求和上下文。
- 先验证动作测试失败，再实现，最终验证实际窗口与资源加载。

## 任务 1：纯 C 控制器

文件：`src/player.h`、`src/player.c`、`tests/player_tests.c`。

接口：`PlayerInit(Player *, const PlayerWorld *)`、`PlayerUpdate(Player *, PlayerInput, const PlayerWorld *, float)`、`PlayerFrame(const Player *)`、`PlayerHeight(const Player *)`。

- [ ] 定义结构、参数和空实现，写左右走、跳、落地、蹲行、冲刺及边界的行为断言。
- [ ] 使用 `gcc -std=c99 -Wall -Wextra -Werror -Isrc tests/player_tests.c src/player.c -o build/player_tests.exe`，运行确认断言失败。
- [ ] 按规格实现速度、重力、地面、状态优先级及动画帧。
- [ ] 重跑测试，要求全部通过，包括 60/120 Hz 位移一致性。

## 任务 2：实际可玩程序

文件：`src/main.c`、`build.ps1`、`run.cmd`、`test.ps1`、`.gitignore`、`README.md`。

- [ ] 宽字符读取三张侧面图集，`LoadImageFromMemory` 解码，`LoadTextureFromImage` 上传，退出时释放。
- [ ] 接入 A/D、空格、S、Shift，固定 120 Hz 更新和镜像绘制。
- [ ] 绘制测试场、操作提示、状态及冷却，可切换碰撞框。
- [ ] 构建脚本使用工程内 GCC 与 raylib 静态库；运行脚本从任意目录启动。
- [ ] 加 `--verify`，实际运行相同控制器与绘制路径，保存各动作截图和 JSON 报告。
- [ ] 编译运行、查看截图、检查原图片未变，更新 README 和计划勾选状态。

## 任务 3：交付

- [ ] 写根目录 `context.jsonl`，验证每行 JSON 和 `git diff --check`。
- [ ] 提交本地 Git；交付 exe、启动入口、操作键和已知动画局限。
