# Task 1：固定拆件骨骼渲染与动作采样

## 实现

- `rig.py` 提供 `PART_ORDER`、`build_rig(view, sizes)`、`sample_pose(action, frame, view)`、`world_transforms(rig, pose)`、`render_pose(parts, rig, pose, size)`。
- `build_rig` 以 512×512 为基准，骨盆根关节位于 `(256,247)`，正背面头部显示约 70×90、躯干约 88×120、骨盆约 78×44；侧面躯干收窄至 58、骨盆收窄至 48，肩关节横向间距 10、髋关节间距 6。双腿关节总长 200。原始骨架的站姿脚踝在约 451、脚底在约 471。`pose["root"]` 是相对该骨架的 `[dx,dy]` 位移，不是绝对坐标。
- 骨架附带 `render_scale=0.8`、`render_anchor=[256,471]`。`render_pose` 对世界关节按 `anchor+(world-anchor)*0.8` 映射，部件显示尺寸也乘 0.8，站姿在 512 画布约 350 像素高，脚底仍落在 471。`world_transforms` 保留未缩放的原始骨架单位，供 JSON 与外部骨骼叠加使用；自定义骨架没有 `render_scale` 时默认 1。
- 每个骨骼记录含名称、父节点、局部坐标、参考长度、静止角、绘制层、部件名、原图像素枢轴和显示尺寸。三视图使用独立遮挡层级：侧面朝左，侧面长发向右偏移 26 并位于脸后；正面长发置于躯干和手臂后；背面长发覆盖躯干。长发高度 190，衣摆高度 176；正背面衣摆宽 76、左右附着点约 ±32，侧面衣摆宽 60、两片附着于腰后 x=10/14 并重叠。
- 短靴含踝筒，按实物三视图改为正面 48×44、侧面 54×44、背面 30×52，旋转枢轴分别靠近对应靴筒，脚踝下方保留约 20 像素鞋底。
- 父链按画布 y 轴向下、正角顺时针的数学约定求世界变换。RGBA 部件使用 Pillow LANCZOS 缩放和 BICUBIC 仿射旋转，先按局部枢轴定位，再按绘制层合成透明画布。
- 待机、慢走、跑步是 60 帧循环动作；跳跃、冲刺、下蹲首尾恢复。侧面走跑双腿相差半周期，支撑脚由两节腿的几何求解保持近地，摆腿有抬脚轨迹。正背面走跑用纵向腿段缩短来表现前后抬腿，避免左右大幅岔腿；`pose["scales"]` 对骨骼图片和父子关节间距同步生效。跳跃根节点上升约 90 骨架像素，侧面双膝向画面左侧收起；下蹲根节点下降约 85 像素，双臂向前保持平衡，下蹲和冲刺支撑脚也通过有限腿 IK 接地。头发和衣摆具有角度滞后。

## 局限与交接

- 拆件原稿未提供精确关节标记；当前枢轴采用各原图宽高的相对位置推定。已按真实裁图和抽样校准大比例与遮挡，但头发、袖口、肩肘、胯膝、脚踝和衣摆的局部像素接缝仍可能需要目视微调。前臂已经包含手；上臂和前臂都有红袖口时，遮挡顺序与长度可能仍需手动调节。
- 缩放后跳跃具有约 72 画布像素的根位移，但骨架仍是设计采样，不是完整动力学模拟。冲刺是短暂前倾与一脚支撑的原地姿势；关卡中的实际水平位移应由播放层/游戏控制器提供。
- 两节腿 IK 仅锁定脚踝目标，没有足尖、脚掌多关节约束，也没有全身动力学；快速切换动作的过渡混合由调用方处理。正背面步态的纵向缩短能维持接缝，但长衣摆遮挡了部分腿部运动，视觉上比侧面步态轻。源图裁剪若有大量透明外沿，比例枢轴需重新标定。
