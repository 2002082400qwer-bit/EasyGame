# 跑步与爆发冲刺重做依据和修改位置

2026-10-14。用户反馈跑步像快走，冲刺可更夸张，要求增加联网运动体态参考。

## 本轮查阅的资料

1. [Australian Athletics：100米各阶段及姿态示意](https://coachathletics.com.au/coaching-education/race-breakdown-and-verbal-cues-for-the-100m)。起跑和初始加速强调整体前倾、前脚蹬出、手脚大幅分离；随后逐渐抬高身体，高速阶段不应一直折腰。查看了该页起跑和姿态演变图的网页参考。本项目将“冲刺”做为一次夸张的游戏爆发，而非持续保持58°前倾的真实高速跑。
2. [LA84 Foundation：Track and Field Coaching Manual](https://digital.la84.org/digital/api/collection/p17103coll14/id/1338/download)，印刷页217–225，Training Sprinters。读取原版PDF并渲染核对章节版面，参考屈膝回收、抬膝、下压和加速的时序，区分高速循环跑与初始加速。该手册是技术教学参考，不把训练练习逐帧照搬成比赛姿势。
3. [Kivi等：不同速度的跑台冲刺运动学](https://pubmed.ncbi.nlm.nih.gov/11932576/)。研究分别测量髋、膝、支撑时间、腾空时间及步频等，支持速度变化涉及动作结构变化，不能只把行走加速播放。
4. [World Athletics：The Sprints](https://worldathletics.org/download/downloadnsa?filename=f411d6b2-f0be-456f-b969-28abad2159ce.pdf&urlslug=the-sprints)。官网检索索引中的技术段落强调脚部回收轨迹、骨盆稳定及恢复期大腿向前上方摆动；直接下载遇到403，未声称检查其未能读取的图表。

研究与教练材料支持的是动作关系，下面的具体角度、时长和关键坐标均是本游戏的美术选择。

## 旧版问题与本轮选择

旧版跑步直接沿用走路的简化足迹，再放大步幅。正式导出测量只有2/60帧双踝离地超过2像素，没有一帧双踝离地超过8像素；膝最大屈曲约108°。这在正常大小下很难读成跑步。此前以同侧手端和脚踝的绝对前后位置判断顺拐，也会在跑步屈膝回收时错误限制摆臂：脚踝仍在后面，大腿已经往前。

新版跑步独立建模：支撑占同脚周期约30%，脚从髋下附近接地，向后蹬出，离地后折叠回收，再抬膝前摆、下压接地。骨盆承重时下降，腾空时抬高。实际导出20/60帧双踝离地超过2像素，其中16帧超过8像素，膝最大屈曲约143°；这些是本轮动画指标，并非所有真实跑者的标准。摆臂反向跟随左右大腿的相对前摆量，正背面使用对应的高度与景深投影，仍各60张。

冲刺增加短促预压、58°侧面前倾、约245骨架像素的前后脚分离和更强衣发后扬，保持前脚支撑及首尾恢复。现有16件刚性拆件只能近似人体和软布运动；没有新增或修改原48张美术拆件。
