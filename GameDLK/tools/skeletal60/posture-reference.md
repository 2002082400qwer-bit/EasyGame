# 落脚姿态与图层修正依据

本轮对应用户反馈：左右脚落地时上身缺乏自然前倾；内侧腿被内侧衣摆遮挡；脖根覆盖胸口。

## 人体运动资料

Thorstensson 等，1984，*Trunk movements in human locomotion*，Acta Physiologica Scandinavica 121(1):9–22。

- 原始研究摘要：https://pubmed.ncbi.nlm.nih.gov/6741583/
- DOI：https://doi.org/10.1111/j.1748-1716.1984.tb10452.x

研究在10名健康成年男性的跑台走、跑中记录躯干运动：每完整跨步有两次上下及前后振动；平均前倾随速度从约6°增至13°，快跑前后俯仰总变化约5°。步行前倾峰值在支撑初期；跑步在该时点相对回收，不能直接照搬步行时序。该研究样本和躯干定义有限，不代表所有人、所有速度的唯一标准。

本项目采用一周期60帧、左右脚相差半周的骨骼近似：侧面慢走6°±2°，第0/30帧支撑初期约8°，第15/45帧回收约4°；跑步平均13°、变化±2.5°，接地约10.5°、半步中段约15.5°，始终保持向前。这些角度是参考研究范围选择的动画参数，不是对实验关节曲线的逐点复刻。头部作小幅反向稳定。正背面维持各自投影，不把侧面前倾变成正背面的横向弯腰。

此前胸部关节固定在髋上方，只有胸部贴图旋转，缺乏整体重心趋势。现在侧面胸部局部位置由 `(0,-52)` 沿倾角绕髋转动，头、手臂、头发随父链移动；腿仍依据接地目标独立求解，不跟随上身旋转而穿地。

## 遮挡规则

- 侧面由远到近：内侧衣摆 → 内侧腿和手臂 → 骨盆 → 后发 → 头部含脖根 → 胸部衣领 → 外侧腿 → 外侧衣摆 → 外侧手臂。允许外侧衣摆按透视遮挡内侧肢体，不把所有衣服都移到双腿之后。
- 三视图头部均先于胸部绘制，让胸部高领覆盖头部拆件自带的脖根和重复领口。后发必须保持在侧脸之后。
- 不修改48张美术拆件；层级、上身位置、姿势JSON、PNG与图集通过同一渲染器一致生成。

## 复现及验收

使用项目Python运行 `tools/skeletal60/build.py --all --reuse-parts`。复用拆件时也重新绑定骨架，避免只改Python而交付JSON仍是旧层序。`comparison/before-posture-fix`首次保存上轮交付快照，已存在则不覆盖；更早的`comparison/before-gait-fix`继续保留。HTML与正常速度GIF默认比较本轮前后。

`test_posture_layers.py`先在旧实现确认4项失败，再验证髋胸真实向量、左右落脚倾角及实色拆件的最终像素遮挡。完整成品验证从动画保存的world坐标计算`posture_quality`，同时检查正式绑定的层序、所有PNG、图集和姿势重放。自然程度仍须以实际画面检查，数值检查不代替美术验收。
