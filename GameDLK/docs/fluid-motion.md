# 2026-10-19：动作连续性改进

用户要求对照《艾希》改善僵硬感。原B站链接返回412，用户补充游戏名称后，改为播放[Steam官方79秒演示](https://store.steampowered.com/app/553640/ICEY/?l=english)，观察10秒附近侧面奔跑及之后的连续动作。本轮改进的是当前已有的走、跑、跳、蹲、冲刺与转向，不增加战斗，也不声称复刻原作内部实现。

## 原因与修改

原版本已经能拼出35个逻辑状态，但每次走跑切换都会重置动作时间，且直接使用新动作的姿势；脚的周期轨迹没有对应260/420像素每秒的世界位移，衣发也跟着整块PNG刚性旋转。静态姿势有效并不代表连续输入自然。

现在使用持久动作控制器：

- 走跑保留同一个相位，在同相位的两套姿势间连续交融；相位根据实际地面位移推进，被边界挡住时不继续踏步。
- 侧面支撑脚保存世界锚点，用双腿IK求目标；离地从前一物理步的真实二维脚位衔接，不重新跳回理想曲线。快速停跑再起步时，原来悬空的脚继续摆动。
- 状态变化从实际显示姿势开始短过渡，支持再次中断。地面动作混合及最终绘制插值后都重新检查鞋底穿地；上身角度限速后重新求胸部枢轴。
- 衣发各自保存角度与角速度，使用解析阻尼弹簧；停止后继续回摆并衰减。原PNG按十段网格弯曲，根部及根部切线固定，保持原图层、枢轴与完整镜像。
- 固定120Hz物理前后的位置与姿态按余量插值。绘制和冲刺残影只读同一份采样，不会多画一次就推进一次动画。

没有调用图片生成器，没有生成新的角色逐帧美术；游戏仍只加载原48张固定PNG，RGBA纹理约10.14 MiB。验证截图位于忽略提交的`verification`，不属于游戏运行资源。最小运行包仍约3.70 MiB。

## 真实动态对照

`verification/motion-before-after-60fps.mp4`：1280×720、60FPS、432帧、7.20秒，文件1,224,861字节。另有30FPS缩小GIF供快速查看；流畅度比较以60FPS视频为准。

左右两边共用同一条真实输入、同一套物理与48件素材。左边直接求原逻辑姿势，附件弯曲为零；右边使用正式主循环相同的MotionUpdate/MotionSample接口。地面世界刻度随跟随镜头滚动，便于观察脚步与位移关系。回放包含起步、走跑、松键重启、释放Ctrl回走、跳接空冲、停止、蹲冲、反向跑及停止后的衣发回摆。

复现：

```powershell
.\build.ps1
.\build\MX002.exe --motion-preview
# 仅编码验证视频时需要ffmpeg；游戏不需要它。
python tools/skeletal60/motion_video.py --ffmpeg C:/path/to/ffmpeg.exe
```

本轮复看了最终视频的连续播放和走跑、跳冲、蹲冲结束等关键阶段。它提供可直接比较的当前效果，不是“已经达到《艾希》商业成品美术质量”的证明。现有三视图转向仍采用短交叉过渡，躯干和四肢仍主要是刚性拆件；本轮柔性网格覆盖头发与衣摆，未新增多角度原画或完整身体蒙皮。

## 技术依据

按用户规则核对官方接口，未引入Spine依赖或复制其运行时：

- [raylib 6.0 rlgl接口及实现](https://github.com/raysan5/raylib/blob/6.0/src/rlgl.h)：纹理绑定、UV、顶点绕序及颜色。
- [Spine官方Mesh文档](https://en.esotericsoftware.com/spine-meshes)：固定部件与连续网格变形的区别。
- [Spine官方Physics文档](https://en.esotericsoftware.com/spine-physics-constraints)：衣发对世界运动的惯性响应、阻尼与后续运动。
- [Glenn Fiedler：Fix Your Timestep!](https://gafferongames.com/post/fix_your_timestep/)：保留固定物理步，并对前后状态按余量插值。
