# 三视图拆件与60帧动作交付计划

用户已经要求执行上一轮建议的拆件骨骼方案，并确认每个动作输出60张图片。指定工程与输出目录优先于隔离工作树建议；在现有codex/movement-prototype分支工作，只提交本任务文件，不覆盖已有重绘流水线、需求文档改动或原图。

## 全局约定与设计

输出目录：`图片/游戏素材/骨骼拆分方式`。三视图原图：`图片/游戏素材/三视图.png`。原动作对照：`图片/游戏素材/diluc-game-sprites/diluc`。

先用image_gen补画三方向各一张4×4透明拆件原稿，再裁出16个固定部件。每张原稿的行优先顺序为：head, torso, pelvis, hair；upper_arm_l, upper_arm_r, forearm_l, forearm_r；thigh_l, thigh_r, shin_l, shin_r；foot_l, foot_r, coat_l, coat_r。前臂包括手，脚单独拆开，隐藏肩/胯/膝补全并留接缝覆盖。躯干不带手臂和腿，披发独立，衣摆不烘焙在大腿。左右标签表示画面左右；侧面l为后侧肢体，r为前侧肢体。正面、侧面、背面分别绑定。

固定美术部件复用，骨骼数据包括父节点、局部枢轴、局部角度和层级。实现慢走、跑步、跳跃、冲刺、待机、下蹲，每方向6组，共18组，每组60张512和256透明PNG、12×5图集、关节变换JSON和预览。每个动作采样60个连续姿势，非循环跳跃/冲刺/下蹲包含恢复到站姿；下蹲中段保持低姿势但有轻微呼吸。标准播放时长1秒，可通过元数据调整。新老对比同一脚底基线和同一显示高度，原8帧按原姿势保持播放，不伪称补帧。浏览器60 FPS预览；GIF仅辅助预览，明确其时间粒度限制。

可重现流水线与验证脚本放`tools/skeletal60`。所有函数、变量、参数写中文说明。对照与补画原稿均记录来源和摘要。无需修改游戏src或覆盖原素材。

## Task 1: 固定拆件骨骼渲染与动作采样

Create: `tools/skeletal60/rig.py`, `tools/skeletal60/test_rig.py`。

接口：`PART_ORDER`上述16项；`build_rig(view: str, sizes: dict[str, tuple[int,int]]) -> dict`返回以512画布为单位的骨骼列表，骨骼记录name,parent,x,y,length,rest_angle,draw_order,part,pivot(部件像素局部点),display_size(部件显示宽高)。头顶约y=30，脚底y=471，根x=256。部件头宽85高100、躯干宽100高140、胯宽85高55，腿长按三视图正常成年比例；站立接缝相互覆盖。侧面朝左，不镜像原图。

`sample_pose(action: str, frame: int, view: str) -> dict`返回包含root[x,y]、angles骨骼名→局部角度偏移（弧度）、scales可选、phase；索引0..59。`world_transforms(rig: dict, pose: dict) -> dict[str, tuple[x,y,angle]]`沿父链合成世界坐标，输出每个关节。`render_pose(parts: dict[str, PIL.Image.Image], rig: dict, pose: dict, size: int=512) -> PIL.Image.Image`用RGBA与高质量重采样旋转固定部件，按绘制层级合成，保留透明背景，保证肩肘、胯膝踝接续。动作采样通过真实骨骼旋转/位移得到，禁止光流或复制旧帧。脚接地采用脚底矫正和有限腿IK，避免明显滑步。部件前臂包含手，头发/衣摆具有滞后运动。

测试先失败后实现：手算父链旋转90度后孩子(0,10)应到(-10,0)；跳跃中段根高度高于首尾且首尾回地面；下蹲中段头部低于站立、首尾恢复；走跑的左右腿异相；循环动作frame0与frame59连续；所有18组每组应有60个不同骨骼姿势；合成小彩色PNG检查旋转父链后绘制位置和透明区域。测试不复写实现数学公式来计算期望。

执行：Bundled Python `-m unittest discover -s tools/skeletal60 -p test_rig.py -v`。报告记录测试和实现局限，不提交其他任务文件。

## Task 2: 三方向透明拆件和遮挡补画

Create: 输出目录下`raw/front_parts.png`,`raw/side_parts.png`,`raw/back_parts.png`,`parts/{view}/{part}.png`,`source-prompts.md`,`sources.json`。

每张原稿image_gen以三视图为参考，透明背景、4×4均匀网格、每格只画对应部件，无标签，无重复整个人。部件头到脚均按中性竖直姿势画，肩胯膝有隐藏部分。目视核对身份、服饰、格子数量和部件类型。必要时针对出错格重新补画，保留原稿。裁图只做确定性格子拆分、透明边界裁剪，不用程序重绘美术。

## Task 3: 完整导出与新老对照验证

Create: `tools/skeletal60/build.py`,`tools/skeletal60/verify.py`与输出目录下`rigs`,`animations`,`frames/{256,512}`,`atlases/{256,512}`,`previews`,`preview.html`,`README.md`,`manifest.json`,`verification.json`。

build调用Task1接口读取Task2部件，输出每方向6动作，60帧序号00..59，12列5行图集，保存每帧骨骼与时间。复制原8帧对照图集到输出目录保持预览独立；如果已有重绘60完整可增加可选对照但不依赖其未完成工作。比较预览有方向、动作、暂停、帧号、速度、背景切换及可见骨骼。使用HTML Canvas以requestAnimationFrame显示60 FPS采样，每组时长统一。

verify真实解码每张PNG，核对2160帧、36图集、18动画、48部件、透明度、帧数、每帧像素摘要、图集与独立帧逐像素一致、画布边缘没有裁切、每组60帧均有不同像素；评估关节连接与脚底基线。目视各方向待机、走、跑、跳、蹲、冲刺的拼图，浏览器实际加载对照预览检查交互和报错。所有来源、生成提示词、局限、如何复用素材写README。仅完成验证后本地Git提交本任务目录、工具、计划和追加context.jsonl。
