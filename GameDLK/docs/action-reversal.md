# 转向与跑姿修正（2026-10-19）

移动中左右反向改为保持侧面移动姿态，立即响应新方向，再从实际膝、肘、手及附件根部的投影位置过渡。数字键仍可切换三视图，但全身横向尺度始终为1，移除原来的20%压窄。

## 动作变化

- 原方向状态机在地面移动反向时，仍串接两段站立转身。现在移动不再经过正面站姿；显式数字键转向仍保留。
- 仅改变mirror并锁住脚踝会让膝盖和肘部突然换边。现在保存完整关节与手末端投影，过渡中重建双段肢体角度与投影长度；头发、衣摆的根部及世界角一起连续过渡。躯干不压窄。
- 每只脚使用独立摆腿/承重秒数，最短新摆腿时间0.16秒。反向发生在全身周期末端时，也不会把完整抬腿挤进两帧；已经抬起的脚只使用剩余抬升高度，避免重复反向使脚越过髋部、触发膝部IK分支翻转。
- 显示插值按膝踝、肘手的实际位置重建投影，保住两端之间预期的脚位轨迹。
- 稳定跑步躯干前倾21～29度，头部反向补偿视线，双臂由实际大腿前后关系交叉驱动。反向先保留原世界倾身，再向新方向发力；走路保持较直立的轮廓。
