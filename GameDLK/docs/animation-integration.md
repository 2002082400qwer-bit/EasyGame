# 60帧动作游戏接入记录

日期：2026-10-15。用户要求将已交付动作整合到C + raylib游戏，并提交EasyGame/main/GameDLK。

## 操作与行为

- A/D或左右键移动，Ctrl跑步，空格跳跃，S/下键下蹲，Shift冲刺。
- 数字1/2/3/4选择正/左/背/右方向。站立转身播放8组原画衔接，对面朝向通过两段90度转身连接。
- 下蹲倒放对应起身动画，松开从当前程度起身。蹲姿冲刺允许直接发起，结束播放站立恢复；继续按住原蹲键不会再次下蹲，释放重按后恢复蹲键。
- 跳跃和冲刺优先响应输入。侧面组合输入及被边界阻挡时仍同步实际朝向；冲刺期间朝向固定。正背视图可以试演同方向完整动作。
- 每组为60帧源图；播放按物理秒数采样。短冲刺不会为展示全部帧而改变0.18秒的物理时长。
