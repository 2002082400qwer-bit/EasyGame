# MX002：C + raylib 横版动作原型

双击根目录 **`run.cmd`** 即可构建最新代码并游玩。已构建程序在 `build/MX002.exe`；它从自身位置寻找资源，可以从其他工作目录启动，请保留 `build` 和 `图片` 的目录关系。首次克隆请先执行 `tools/setup.ps1` 安装工程内的官方构建依赖。

游戏现已接入 `diluc-redrawn-60` 的全部35组动作图集，每组60帧。包含三方向待机、慢走、跑步、跳跃、冲刺，八组转身，以及蹲起、起跳、站姿冲刺和蹲姿冲刺后站立的衔接。

| 按键 | 功能 |
| --- | --- |
| A / D，← / → | 左右走；同时按左右则停止 |
| Ctrl + 移动 | 跑步，松开Ctrl回到慢走 |
| 空格 | 地面跳跃；无二段跳 |
| S / ↓ | 按住下蹲，可缓慢移动；松开站起 |
| 左右 Shift | 按下冲刺，朝移动方向或当前面向；按住不会连续触发 |
| S + Shift | 蹲姿冲刺，结束站立；原来的蹲键松开并重新按下后才能再次下蹲 |
| 1 / 2 / 3 / 4 | 正面 / 左侧 / 背面 / 右侧，播放相应转身衔接 |
| R | 重置位置和动作 |
| F1 | 切换碰撞框显示 |
| Esc | 退出 |

冲刺持续0.18秒，开始后冷却0.6秒；空中允许一次，落地恢复。下蹲时不能直接跳跃，松开蹲键后可以起跳。地面和左右边缘有碰撞；当前为单屏动作测试场。

数字键切换站立朝向：180度转身串接两段90度转身。选择正面或背面后，可用该方向的全部动作在横版场地中试演；选择侧面后，移动自动朝左或朝右。跳跃、冲刺和蹲行优先响应实际侧面移动方向，冲刺期间锁定方向；空中提出的正背转向在回到可转身状态后播放。

## 构建与测试

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1
```

`test.ps1`执行32项物理断言和3158项动画断言，覆盖三方向动作链、八组转向、镜像、组合输入、边界朝向、冲刺锁定、蹲冲站立和落地恢复。

`verify.ps1`从其他工作目录启动真实OpenGL程序，检查35张图集的首、中、末帧绘制，运行四朝向的52个动作场景及8个转向场景，共95项GPU检查。在 `verification` 输出95张截图和 `report.json`；截图在提交绘制批次后、交换窗口缓冲前读取，与报告帧号一致。脚本另外在隔离副本中验证资源缺失和截断PNG的具体报错及退出码。也可以直接执行 `build/MX002.exe --verify` 只运行GPU检查。这些检查不代替真人按键手感测试。

使用C99、raylib 6.0、w64devkit GCC 16.2.0，编译启用 `-Wall -Wextra -Werror`。编译器与库在工程内，不修改全局环境；`tools` 内下载和工具链、`third_party`、构建与验证产物不纳入Git。新克隆工程先执行 `tools/setup.ps1` 下载官方依赖，再构建。

## 美术与物理

使用 `图片/游戏素材/diluc-redrawn-60/atlases` 下的35张3072×1280图集，按12列、5行切出256×256帧。人物侧面原图朝左，普通右侧动作通过水平镜像；专门绘制的右转衔接直接播放，不再次镜像。原始图片保持不变，脚底锚点 `(0.5, 0.92)`；物理每秒更新120次，渲染帧率独立。

待机播放独立呼吸循环。下蹲倒放对应的起身动画，保持第00帧蹲姿，松开后从当前程度正放起身；碰撞框由156降至98像素，保持脚底位置。起跳衔接占最初0.10秒，随后根据物理飞行进度使用跳跃20～39帧，真实落地后播放40～59帧恢复，避免在空中重新蓄力。

站姿冲刺先播放起冲衔接再播放冲刺主体；蹲姿冲刺在0.18秒移动段播放该组前40帧，随后用0.12秒播放末20帧站立恢复。短动作按物理时长映射60帧资源；实际屏幕刷新可能跳过中间采样帧，不会为显示每张图而延长冲刺位移时间。待机完整循环2秒，慢走1秒，跑步0.65秒，90度转身0.16秒。

资源采用四图集LRU缓存，纹理数据最多约60 MiB，不一次性上传35张大图。启动检查完整资源清单，实际使用时解码；缺图、错误尺寸、PNG损坏或上传失败会报告具体文件名并返回非零退出码。

`src/player.c`负责可测试的移动物理，参数集中在`src/player.h`；`src/animation.c`负责35组动作选择、60帧时间映射、转身与镜像；`src/main.c`负责键盘、图集缓存、窗口和GPU验证。Windows下通过宽字符文件API读取中文路径，再交给raylib内存解码。本轮代码修改位置见`docs/animation-integration.md`。
