## 2026-10-14：步幅与顺拐修正

走跑与冲刺已经改为同侧脚向前时手向后，双臂采用同一朝向的屈肘，侧面摆臂由实际脚步相位反向驱动。走路半步幅由19增到52，跑步由31增到82；同时通过腿可达距离调整骨盆，让大步幅的支撑脚仍能接地。跑步增加屈肘、收腿和短暂双脚腾空，冲刺增加前倾与前后腿伸展，正背面加大抬脚和手臂景深变化。所有动作的人物显示大小保持一致。

打开`preview.html`默认比较修正前/后的完整60帧。`comparison/before-gait-fix`保留此前的图集、绑定和姿势数据，查看`previews/gait_comparison_normal_speed.gif`可在正常速度下比较侧面走、跑、冲刺：上排修正前，下排修正后。此辅助GIF取样30FPS以兼容GIF计时，正式PNG和HTML仍是每动作60帧。`verification.json`新增对旧版与新版实际导出世界坐标的步态指标，检查同侧手脚配合、脚和手的跨度及腾空帧。

本套素材以MX002中的`三视图.png`为设计参考，使用固定透明拆件和父子骨骼合成动作。原先的逐帧素材保存在原目录。新美术由内置image_gen分解补绘，补全肩、肘、胯、膝的遮挡区域；头发和衣摆独立，所有动作复用同一套部件。补绘可能带来少量服饰纹样差异，提示词和生成原稿均已保留。

## 查看对比

直接双击`preview.html`，不需要安装游戏引擎，也不需要启动服务器。选择正面、侧面、背面和动作，可暂停、逐帧、拖动进度、降速、显示骨骼与切换背景。左右按站立人物高度校准，并使用同一脚底基线、同一动作周期。

左侧可选原8个姿势的保持播放，或工程内已经完成的逐帧重绘60帧快照，右侧是新骨骼60张采样图。重绘流水线仍有未完成组，仅对已存在完整60帧图集与索引的组提供此选项；本次导出时可用范围以`manifest.json`中的`redrawn`字段为准。待机、下蹲的原8帧对照展示游戏借用的跳跃第7帧/第0帧，不冒充专门的动画。浏览器采用时间戳以60 FPS取帧；显示器实际刷新率会影响可见刷新次数。跳跃、冲刺、下蹲演示会重复，索引里本身标记为非循环。

`previews`有每组关键阶段拼图和三方向汇总图，方便检查动作。GIF仅作辅助半速展示；60帧正式对比以HTML和PNG为准。

## 交付内容

- `parts/front、side、back`：各16张透明PNG，共48部件；前臂包括手。
- `raw`：三方向拆件原稿、侧面布局初稿和独立补图，保留修正过程。
- `rigs`：三套骨架，含父节点、关节坐标、绘制层级、原图枢轴和显示尺寸。
- `animations`：18组动作，各60个姿势与世界关节坐标，角度单位为弧度。
- `frames/256、frames/512`：每种尺寸1080张PNG，合计2160张。
- `atlases/256、atlases/512`：每组12列×5行；256图集为3072×1280，512图集为6144×2560；行优先共60帧。
- `comparison`：原动作对照图集的无损副本，供预览离线使用。
- `manifest.json`：动作、尺寸、播放速度、循环属性、脚底锚点及路径。
- `sources.json、source-prompts.md`：美术来源、裁格范围、摘要及完整提示词。正面右前臂镜像复用干净左前臂；三方向长发和背面右前臂使用独立补图。
- `verification.json`：真实解码结果、逐帧像素摘要、图集一致性、透明边界、去重和元数据重放结果。

三方向各包括：待机、慢走、跑步、跳跃、冲刺、下蹲。每组60张图片来自连续的骨骼姿势采样，并非60张手绘原画，也没有对旧8帧使用光流。默认周期1秒，60 FPS；游戏可以更改播放时长。下蹲包含蹲下、短暂维持与站起，运行时若需要长时间保持，可停在中段。

## C游戏使用

可直接使用PNG图集，按`frame % 12`和`frame / 12`选择矩形，单帧256或512像素，脚底锚点为`(0.5,0.92)`。侧面朝左；朝右可整体镜像。具体播放帧数改为60、列数改为12后，可沿用现有按帧绘制方式。

骨骼JSON是本流水线的自定义格式，不是Spine工程文件或其运行库格式。若希望游戏实时驱动骨骼，需要实现同样的父子矩阵、枢轴变换、缩放和层级绘制。骨架的`render_scale`与`render_anchor`对所有动作统一缩放，给跳跃保留顶部空间；动画里的`world`为缩放前的骨架坐标，显示坐标为`anchor + (world - anchor) × render_scale`。本次任务提供独立素材和对照预览，没有替换现有游戏程序的资源加载逻辑。

## 重新导出

工程根目录运行带Pillow和NumPy的Python：

```powershell
python -m unittest discover -s tools/skeletal60 -p 'test_*.py' -v
python tools/skeletal60/build.py --all
python tools/skeletal60/verify.py
```

仅校准抽样时省略`--all`。调完骨架后应重新生成绑定数据再导出，不使用旧绑定。原稿的少数格子并非严格等宽等高，裁格边界已经人工核对并记录，避免切断衣摆或引入邻格头发。

关节、步态和接地由程序驱动。正背面的景深变化采用有限的部件缩放与位移，复杂转身、明显透视和夸张战斗动作仍需要新的角度补图。本次未增加转身或战斗。

参考文档：[Pillow图像变换](https://pillow.readthedocs.io/en/stable/reference/Image.html)、[Spine骨骼原理](https://esotericsoftware.com/spine-basic-concepts)。
